The bot places an outbound call through Twilio, which is bridged via Pipecat to OpenAI's Realtime API for speech-to-speech generation; transcripts are captured from Realtime's own transcription events and logged per turn, and ngrok exposes the local server's public URL for Twilio's media stream. Realtime was chosen over a cascading STT -> LLM -> TTS pipeline because the evaluation's first and hardest gate is whether the bot holds a coherent voice conversation: Realtime handles turn-taking and barge-in natively rather than requiring hand-tuned endpointing, and interruption handling is itself one of the required test scenarios. Pipecat was chosen so the telephony-to-audio plumbing (Twilio media streams, framing, format conversion) didn't have to be built from scratch.

ngrok was used instead of a real deployment because this system runs for a batch of test calls, not as a continuously available service. The main tradeoff accepted with Realtime is less control over the patient caller's exact wording and higher per-minute cost than a cascading pipeline, which was judged acceptable since the spec asks for a realistic caller behaving like a real user, not a scripted benchmark runner. Because Twilio's account was stuck in compliance verification during development, the entire conversation loop -- turn-taking, pacing, and interruption behavior -- was built and tuned against a laptop mic first, before telephony was wired in at all.

Two bugs only surfaced once real calls were placed, since neither is reachable from local mic testing. First, the pipeline's internal audio rate was left at Twilio's 8kHz instead of the 24kHz OpenAI's Realtime API expects, which silently produced audio at the wrong pitch and speed until calls went dead-silent with no error at all. Second, semantic turn detection kept mistaking the clean sentence-final pauses inside the target line's scripted IVR announcement for the caller's turn ending, causing the bot to barge in at the start of every call; switching to plain silence-duration VAD with a longer window fixed it.
